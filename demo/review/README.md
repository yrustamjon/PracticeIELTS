# PracticeIELTS — alohida HTML demolar

Avval dizayn va oqimni kelishish uchun. Asosiy React/Django ilovasiga ulanmagan.

## Ochish

`index.html` faylini Chrome yoki Safari orqali oching (ikki marta bosing).
Npm, Python, backend va internet kerak emas. Fayllarni bitta papkada saqlang.

Mac terminalida, loyiha ildizidan:

```sh
open demo/review/index.html
```

## Alohida fayllar

- `01-library.html`: manba → kitob → test; qidiruv va pagination.
- `02-test-modes.html`: Full / Part 1–4 → Mock / Practice → vaqt yoki daraja.
- `03-admin.html`: kitob/test qo‘shish, Part kartalari va 4 qadamli forma.
- `04-practice.html`: sahifalangan va ichki scrolli ro‘yxat; 3 daraja; audio va lokal javob tekshirish.
- `05-mock.html`: 4 part, har birida 3 ta original savol; jami 12 ta. Matn ichida blanks, radio va select; yonma-yon tasklar; lokal saqlash va natija.

## Demodagi ishlash chegaralari

Audio HTML ichiga joylangan original sintez qilingan namuna. Cambridge nomlari faqat tuzilmani ko‘rsatadi; Cambridge audiosi yoki savollari emas.

Adminning fayl tanlash bosqichi lokal preview va fayl nomini ko‘rsatadi. Serverga yuklamaydi, PDF tahlili yoki transkripsiya qilmaydi. Admin va Practice holati sahifa yopilguncha turadi. Mock javoblari brauzer imkon bersa localStorage orqali saqlanadi; sahifada saqlash holati ko‘rsatiladi. Yangi urinish uchun natija oynasida “Qayta boshlash”ni bosing.

Vaqtli qisqa Mock: Full demo uchun 3 daqiqa, alohida Part uchun 1 daqiqa. Sanoq audio boshlanganida ishlaydi. Yangilashdan keyin vaqt saqlanadi, audioni esa foydalanuvchi qayta boshlaydi. Bu qisqa interfeys namunasi, rasmiy IELTS test davomiyligi yoki band bahosi emas.

Dizayn bo‘yicha kelishilgach, kerakli oqimlar asosiy ilovaga alohida ulanadi.
