# READING-ML-01 working contract

Reading and Listening share provider/queue infrastructure only; domain extraction/review prompts and data remain independent. This increment changes Reading only. No model is trained from scratch and 90% automation is a measured target, not a result.

## Job model (reading.models.ReadingImportJob)
owner FK User; source FileField using source_path; source_name CharField; source_digest CharField64; book CharField150 blank; license CharField500; rights_confirmed bool; state choices queued/running/needs_review/blocked/failed/completed; stage CharField80; attempts positive int; progress JSON; candidates JSON list; findings JSON list; metrics JSON dict; error_code CharField80; error_message CharField500; created_at/updated_at/started_at/finished_at. published_papers JSON list. No automatic publication. A candidate is {book,test,passage,content,keys,source_pages,key_pages}; content follows existing VersionInput. Candidate may be incomplete: keep omissions/findings honest until corrected.

## API (root agent owns model/API/tests)
- GET reading-imports/capabilities/ -> {available,provider,model,review_model,reason,max_file_mb:50,max_pages:200}; no secrets.
- GET reading-imports/ -> paginated owned jobs (admins may access other jobs by detail permissions consistent with Reading).
- POST reading-imports/ multipart source:PDF, book?:text, license:text, rights_confirmed:true. Validate PDF<=50MiB, <=200pages, readable. Save private file, queue worker; broker error retained as blocked/error. response201 job.
- GET reading-imports/{id}/ -> all job fields safe for authorized owner/editor, plus source_page_count; source file path/URL never returned.
- GET reading-imports/{id}/source-pages/{page}/ -> editor-authorized PNG, private/no-store, bounded rendering.
- POST reading-imports/{id}/retry/ -> queue existing failed/blocked job, reject concurrent running; no duplicate worker/model calls after review/completed.
- PATCH reading-imports/{id}/ -> {candidates?:list,findings?:list}. Allowed only needs_review. Validate bounded shape; do not trust client to erase original findings. Resolution is explicit {finding_id, resolution_note}; use `resolutions` list in PATCH. Save native candidate edits. Deterministic validation always rerun at approval. Store unresolved source/model issues; no confidence percentage fabricated.
- POST reading-imports/{id}/approve/ {candidate_index:int,confirm_review:true} -> {paper,version}; require rights, completed independent review and deterministic VersionInput validity; no unresolved blocking findings for that candidate (human resolution note required). New immutable version; pin published pointer. One candidate published once using published_papers entries {candidate_index,paper,version}. Return existing mapping idempotently. Only mark completed when every candidate published.

Findings: {id:string,candidate_index:int|null,stage:extract|review|validation,severity:error|warning,message:string,source_pages:int[],path:string?,resolved?:bool,resolution_note?:string}. Confidence uses model-reported evidence only, never fabricated accuracy. Metrics are actual counts/calls/durations/check results. Missing keys/unsupported image or question structure are blocking findings. Images/diagrams must never be silently omitted.

## Backend worker/provider (pipeline agent owns reading/ml/* and reading/tasks.py)
`reading.ml.provider.capabilities()` returns safe provider readiness. Environment READING_ML_BASE_URL, READING_ML_API_KEY, READING_ML_MODEL, READING_ML_REVIEW_MODEL. OpenAI-compatible /chat/completions configurable endpoint, TLS verification, explicit bounded timeouts, sanitized errors, no raw source/keys/credentials in logs. Must not make paid calls without configured/user-authorized connection. No default cloud endpoint/model/key. Independent review is a separate call, with original page evidence and prepared candidate supplied. Optional one bounded correction cycle then independent recheck; unresolved findings remain. Store real model names/call counts/evidence.
`reading.tasks.process_reading_import(job_id)` Celery task calls pipeline. Job claim/idempotence under database lock, stage/progress persistence, no publication or direct ReadingVersion mutation. Missing provider -> blocked/provider_not_configured; preserve source for retry. Worker writes candidates/findings/metrics and needs_review only after actual extraction and independent review. Model failure -> failed, safe error. PDF text extraction: use pypdfium2, real Tesseract OCR fallback, page-number evidence; bounded pages/image rendering/OCR subprocess with timeout. Full-book handling should not silently truncate pages: inventory/chunk source and report incomplete output. Retain original source privately.
